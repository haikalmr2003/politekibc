# POLITEK IBC - Digital Skill Center

React + Vite starter project with Tailwind CSS, React Router, Framer Motion and React Icons.

Setup:
1. npm install
2. npm run dev

Notes:
- This is a frontend-only demo. Placement test and admin pages store demo data in localStorage.
- Fonts: Poppins loaded from Google Fonts.
- Colors configured in tailwind.config.js (ibc-red, ibc-blue, ibc-light).

Folder structure:
- src/components: reusable UI pieces
- src/pages: main routes (Home, Placement Test, Admin pages)
- src/data: dummy data and question generator
